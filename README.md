### 💫 关于我 (About Me)

你好！我是一名重庆邮电大学的本科学生，正在持续探索 Rust 开发与 AI 工程。我喜欢从想法出发构建真实可用的项目，也享受研究底层技术和打磨开发体验的过程。

- 🔭 **当前专注于**：Rust 工程、网络工具与 AI 应用开发。
- 🌱 **正在学习**：Candle、LLM 推理以及高性能系统设计。
- 🧩 **项目方向**：跨设备互联、Coding Agent 编排和开发者工具。
- 💬 **欢迎交流**：Rust、Candle、LLM 应用、系统开发，以及任何有趣的开源项目。
