### 💫 关于我 (About Me)

你好！我是一名全栈开发工程师。我热爱技术，享受从零到一构建应用并将其部署上线的成就感。我注重代码质量、系统性能与用户交互体验。

- 🔭 **当前专注于**：现代前端技术栈 (React, Next.js, Vue) 与高性能后端架构 (Node.js, Go)。
- 💡 **技术理念**：编写易于维护、高性能的代码，用技术解决现实生活中的痛点。
- 🌱 **正在学习**：系统设计与微服务架构、大语言模型 (LLM) 应用开发与工程化落地。
- 💬 **与我交流**：JavaScript/TypeScript、Web 性能优化、接口设计、或者任何好玩的新技术！
